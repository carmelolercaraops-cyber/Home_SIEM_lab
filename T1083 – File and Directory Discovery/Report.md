## Reason for Classifying as True Positive

Sysmon Event ID 1 confirmed the creation of a `cmd.exe` process executing recursive directory enumeration commands.

The observed command line contained multiple `dir /s` commands and a `tree /F` command targeting filesystem locations including:

`C:\`

`C:\Documents and Settings`

`C:\Program Files`

`%systemdrive%\Users`

`%userprofile%\AppData\Roaming\Microsoft\Windows\Recent`

`%userprofile%\Desktop`

The observed command line was:

`"cmd.exe" /c dir /s c:\ >> %%temp%%\T1083Test1.txt & dir /s "c:\Documents and Settings" >> %%temp%%\T1083Test1.txt & dir /s "c:\Program Files\" >> %%temp%%\T1083Test1.txt & dir "%%systemdrive%%\Users\*.*" >> %%temp%%\T1083Test1.txt & dir "%%userprofile%%\AppData\Roaming\Microsoft\Windows\Recent\*.*" >> %%temp%%\T1083Test1.txt & dir "%%userprofile%%\Desktop\*.*" >> %%temp%%\T1083Test1.txt & tree /F >> %%temp%%\T1083Test1.txt`

The execution of recursive `dir /s` and `tree /F` commands directly corresponds to MITRE ATT&CK technique T1083 - File and Directory Discovery.

The Atomic Red Team T1083-1 test generated the expected Sysmon telemetry. The Atomic execution subsequently timed out, but the expected process creation event was successfully observed and the corresponding Splunk detection and real-time alert were triggered.

## Reason for Escalating the Alert

The activity involves recursive enumeration of files and directories across multiple filesystem locations.

File and Directory Discovery is relevant to SOC monitoring because attackers may use similar commands to understand the filesystem structure and identify files, directories, user data, and other potentially relevant information on a compromised host.

In this lab, the activity was intentionally generated by Atomic Red Team and is classified as a confirmed test-positive event.

The parent process:

`C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe`

and the associated process lineage are documented as contextual investigation information and are not used as the primary indicator for the T1083 detection.

## Recommended Remediation Actions

- Validate whether the recursive directory enumeration was authorized.
- Review the parent/child process relationship involving `powershell.exe` and `cmd.exe`.
- Investigate additional discovery activity generated by the same user or host around the execution time.
- Review related Sysmon Process Create events for additional filesystem discovery commands.
- For unauthorized activity, isolate the endpoint and investigate for further reconnaissance or post-compromise activity.
- Consider monitoring recursive directory enumeration commands such as `dir /s` and `tree /F` in conjunction with process lineage and user context.
