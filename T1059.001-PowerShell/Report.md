## Reason for Classifying as True Positive

Sysmon Event ID 1 confirmed the creation of a PowerShell process executing an encoded command through cmd.exe.

PowerShell Script Block Logging (Event ID 4104) independently confirmed execution of the decoded script content:

`Write-Host 'Hello, from PowerShell!'`

The Atomic Red Team test completed successfully with exit code 0, confirming that the observed activity corresponds to the executed TTP rather than unrelated PowerShell activity.

## Reason for Escalating the Alert

The activity includes PowerShell execution with an encoded command (`-e` / `-EncodedCommand`) and an indirect process chain involving `cmd.exe`.

Encoded PowerShell execution can be used to conceal command content and is therefore relevant for SOC investigation and detection.

In this lab, the activity was intentionally generated by Atomic Red Team and is classified as a confirmed test-positive event.

## Recommended Remediation Actions

- Validate whether the PowerShell execution was authorized.
- Review the parent/child process chain and associated Script Block Logging events.
- Investigate any additional activity generated by the same user or host around the execution time.
- For unauthorized activity, isolate the endpoint and investigate for additional PowerShell-based execution.
- Consider enforcing PowerShell logging and monitoring encoded PowerShell execution.
