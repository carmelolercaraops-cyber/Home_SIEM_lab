# Splunk Alert - T1082 System Information Discovery

## Alert Overview

A real-time Splunk alert was configured to detect System Information Discovery through Sysmon Process Create telemetry.

The alert is associated with MITRE ATT&CK technique **T1082 - System Information Discovery**.

The purpose of the alert is to identify the execution of `systeminfo.exe` generated by the controlled Atomic Red Team test.

## Detection Query

    index=siem_lab sourcetype="WinEventLog:Sysmon"
    Message="*systeminfo.exe*"

## Alert Configuration

- **Alert type:** Real-time
- **Trigger condition:** Search returns matching results
- **Severity:** Medium
- **Action:** Add to Triggered Alerts
- **Expiration:** 30 days
- **Index:** `siem_lab`
- **Sourcetype:** `WinEventLog:Sysmon`

## Detection Logic

The alert:

1. Searches Sysmon telemetry stored in the `siem_lab` index.
2. Limits the search to `WinEventLog:Sysmon` events.
3. Searches for the execution of `systeminfo.exe`.
4. Matches the process associated with System Information Discovery activity.
5. Generates an alert when matching telemetry is observed.

## Validation

The alert was validated using the same controlled Atomic Red Team activity used for the corresponding analysis.

The laboratory activity generated a `systeminfo.exe` process creation event.

The telemetry was successfully ingested by Splunk, matched the detection query, and triggered the configured real-time alert.

This confirms the complete detection workflow:

    Controlled Activity
            ↓
    Sysmon Event
            ↓
    Splunk Universal Forwarder
            ↓
    Splunk Enterprise
            ↓
    SPL Detection
            ↓
    Real-Time Alert
            ↓
    Triggered Alert

## Classification

The alert represents a **confirmed laboratory test-positive event**.

The activity was intentionally generated as part of the Home SIEM Lab and does not represent evidence of a real-world compromise.

## Notes

The detection is intentionally focused on the execution of `systeminfo.exe`, which directly represents MITRE ATT&CK T1082 - System Information Discovery.

The observed command line also contained an additional registry query:

    cmd.exe /c systeminfo & reg query HKLM\SYSTEM\CurrentControlSet\Services\Disk\Enum

The registry query is documented as contextual activity from the same execution and is not used as the primary detection criterion.

In a production environment, a broader detection strategy would be required to identify suspicious system information discovery activity without relying exclusively on a single known process name.
