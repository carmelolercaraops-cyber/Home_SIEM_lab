# SOC Investigation Report

## Time of activity

07/10/2026 17:01:23–17:01:24 CEST

## List of Affected Entities

- Host: LAB-WIN01
- User: LAB-WIN01\LABUSER
- Process: systeminfo.exe
- Parent process: cmd.exe
- Sysmon Event ID: 1
- MITRE ATT&CK: T1082 - System Information Discovery

## Reason for Classifying as True Positive

Sysmon Event ID 1 confirmed the creation of a `systeminfo.exe` process.

The process was associated with `cmd.exe` as the parent process.

The parent command line was:

`cmd.exe /c systeminfo & reg query HKLM\SYSTEM\CurrentControlSet\Services\Disk\Enum`

The execution of `systeminfo.exe` directly corresponds to MITRE ATT&CK technique T1082 - System Information Discovery.

The Atomic Red Team T1082-1 test completed successfully, confirming that the observed activity corresponds to the intentionally executed laboratory TTP rather than unrelated system activity.

## Reason for Escalating the Alert

The activity involves the execution of `systeminfo.exe`, a Windows utility capable of collecting detailed information about the operating system and host configuration.

System information discovery is relevant to SOC monitoring because attackers may use similar commands to gather information about a compromised host during reconnaissance.

In this lab, the activity was intentionally generated by Atomic Red Team and is classified as a confirmed test-positive event.

The same command line also contained a registry query against:

`HKLM\SYSTEM\CurrentControlSet\Services\Disk\Enum`

This additional activity is documented as contextual information and is not used as the primary indicator for the T1082 detection.

## Recommended Remediation Actions

- Validate whether the `systeminfo.exe` execution was authorized.
- Review the parent/child process relationship involving `cmd.exe`.
- Investigate additional discovery activity generated by the same user or host around the execution time.
- Review related Sysmon Process Create events for additional reconnaissance commands.
- For unauthorized activity, isolate the endpoint and investigate for further discovery or post-compromise activity.
- Consider monitoring execution of system information discovery utilities in conjunction with process lineage and user context.
