# T1059.003 - Windows Command Shell

## Objective

Validate detection of Windows Command Shell execution (`cmd.exe`) using Atomic Red Team, Windows Sysmon telemetry, Splunk, and a real-time alert.

The test was performed on a Windows endpoint monitored by Splunk Universal Forwarder.

## Atomic Red Team

- Technique: T1059.003 - Windows Command Shell
- Atomic Test: T1059.003-3
- Framework: Atomic Red Team
- Test execution: Successful
- Executed command: `cmd /c echo Hello, from CMD!`

## Telemetry

The execution generated a Sysmon Process Create event (Event ID 1).

Relevant telemetry included:

- `Image: C:\Windows\System32\cmd.exe`
- `CommandLine: cmd /c echo Hello, from CMD!`
- `ParentImage`
- `ParentProcessId`
- `ProcessId`
- User and integrity information
- SHA256 process hash

The process lineage was investigated using the `ProcessId` and `ParentProcessId` fields.

## Splunk Detection

The detection searches the `siem_lab` index for Sysmon Process Create events containing the command line generated by the Atomic Red Team test.

Validated SPL query:

    index=siem_lab sourcetype="WinEventLog:Sysmon"
    Message="*Process Create*"
    Message="*CommandLine: cmd  /c echo Hello, from CMD!*"

The query returned a single matching event during validation.

The detection was intentionally kept focused on the observable command execution generated by the controlled T1059.003 activity.

## Alert

A Splunk real-time alert was created from the detection query.

Configuration:

- Alert type: Real-time
- Trigger condition: Per result
- Severity: Medium
- Triggered Alerts: Enabled
- Expiration: 30 days

The detection was tested by executing the Atomic Red Team test again.

The Splunk alert triggered successfully.

## Detection Flow

Atomic Red Team → cmd.exe → Sysmon Event ID 1 → Splunk Universal Forwarder → Splunk index=siem_lab → SPL Detection → Real-time Alert

## Investigation Methodology

The investigation followed a structured SOC investigation workflow.

### 1. Timeline

The investigation started by identifying the time window surrounding the Atomic Red Team T1059.003-3 execution.

The Splunk search was then narrowed to the relevant period to reduce the number of unrelated `cmd.exe` events.

### 2. Noise Reduction

The initial investigation contained multiple `cmd.exe` process creation events, including activity generated by Windows and Splunk infrastructure.

The command line was therefore used as a primary investigative pivot to identify the event corresponding to the controlled Atomic Red Team execution.

The investigation also identified unrelated Splunk-generated command activity, which was not considered part of the Atomic Red Team process chain.

### 3. Hypothesis

The investigation hypothesis was that the Atomic Red Team test would generate a Sysmon Process Create event containing the expected command:

`cmd /c echo Hello, from CMD!`

The command line was used to isolate the relevant event from unrelated `cmd.exe` activity.

### 4. Process Investigation

The relevant Sysmon event was identified and the associated process identifiers were reviewed.

The `ProcessId` and `ParentProcessId` fields were used to reconstruct the process lineage.

The lineage was investigated by following:

`ProcessId` → `ParentProcessId` → parent process → previous parent process

This allowed the analyst to determine which process launched `cmd.exe` and to distinguish the controlled execution from unrelated command shell activity.

### 5. TTP Identification

The observed execution of `cmd.exe` corresponds to **MITRE ATT&CK T1059.003 - Windows Command Shell**.

The command line:

`cmd /c echo Hello, from CMD!`

provided direct evidence of command shell execution associated with the controlled Atomic Red Team test.

### 6. Detection Development

After identifying the relevant Sysmon event and validating the process context, the detection was developed using a focused SPL query targeting the observable command line generated by the test.

Validated SPL:

    index=siem_lab sourcetype="WinEventLog:Sysmon"
    Message="*Process Create*"
    Message="*CommandLine: cmd  /c echo Hello, from CMD!*"

The detection was intentionally kept focused on the observed laboratory activity.

### 7. Detection Validation

The SPL detection returned the expected event during validation.

A real-time Splunk alert was then configured using the same detection logic.

The Atomic Red Team T1059.003-3 test was executed again and the configured alert triggered successfully.

This validated the complete workflow from controlled activity to telemetry, detection, and real-time alerting.

## Process Lineage

The process chain can be reconstructed by following the Sysmon process identifiers:

`ProcessId` → `ParentProcessId` → parent process → previous parent process

Process lineage provides additional context during investigation and can help determine which process launched `cmd.exe`.

Lineage is treated as an investigative pivot rather than automatically being used as a detection criterion.
